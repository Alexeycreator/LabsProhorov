# Комментарии оставляем в виде:
1. Стадия «Создания и добавления» (Новый функционал)<br />
_Добавление новой функциональности_: `feat: добавлена обработка входящих данных`<br />
_Добавление новых данных, зависимостей или ресурсов_: `add: добавлена зависимость EF Core`<br />
2. Стадия «Исправления и улучшения» (Поддержка)<br />
_Исправление бага_: `fix: исправлен расчет площади квадрата`<br />
_Удаление устаревшего кода, файлов, функций_: `remove / delete: удалена функция расчета периметра`
